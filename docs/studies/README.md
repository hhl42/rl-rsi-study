# Study notes

These notes explain what each reference contributes, what it does not establish, and what we should check next. Start with the [survey](../02-survey.md) for the shared concepts and follow the [study plan](../01-study-plan.md) for the sequence. Reading a note does not complete a paper review or reproduce a result.

The [source register](../../references/README.md) owns bibliographic details and review depth. Every original reference has a study note below. The X article is available as a supplied PDF. The added foundational papers have a shared reading worksheet; detailed reviews of most remain pending.
